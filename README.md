# 🚀 Enterprise URL Shortener

A scalable URL shortening service built with **React, Spring Boot, MySQL, and Redis**, designed for low latency, high throughput, and strong system design fundamentals.

---

## ✨ Features
- 🔗 Generate short URLs using Base62 encoding
- ⚡ Fast redirects with Redis caching
- 📊 Click analytics & expiry support
- 🚦 Token bucket rate limiting
- 🧠 Cache-aside pattern to reduce DB load
- ⏳ Scheduler for expired URL cleanup

---

## 🛠️ Tech Stack
- **Frontend:** React, Css
- **Backend:** Spring Boot, Java 17, JPA  
- **Database:** MySQL  
- **Cache:** Redis  
- **Build Tool:** Mave
